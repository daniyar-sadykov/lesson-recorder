# Задачи проекта

Одна задача это каталог `docs/tasks/<slug>/`. План сохраняется файлом всегда, даже для задачи на один заход: разговор после `/clear` не сохраняется.

| Размер задачи | Что лежит в каталоге |
|---|---|
| закрывается за один заход | `plan.md`, утверждённый до кода |
| не влезает в одну сессию | спека, список фич с признаком «проходит», `progress.md` |
| непонятно, с какой стороны | открытые вопросы, решения по ним, сквозной срез через все слои |

Сессия многосессионной задачи начинается с чтения `progress.md`, `git log` и прогона тестов, заканчивается коммитом и строкой в `progress.md`.
